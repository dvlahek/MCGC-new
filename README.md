# MCGC-new

Minimal research prototype for a **Multi-Agent Chemotactic Graph Classifier (MCGC)**.

The working idea is to classify a query by asking, for each candidate class, whether multiple class-conditioned walkers can find a geometrically plausible and coherent path of increasing class evidence through a k-nearest-neighbour graph.

This repository is intentionally small and reproducible. It starts with synthetic benchmarks and deterministic tests before any larger empirical claims are made.

> Status: experimental v0.1 research prototype. No novelty or performance claim is implied by the code alone.
